从到账到调用记录

按这个顺序检查。

  1. 选好模型和分组

    打开模型广场，复制完整模型名，核对接口类型、分组和客户端限制。Codex 分组倍率为 Sale 0.08 / Plus 0.15 / Pro 0.25 / Pro+ 0.35；倍率不是一条请求的价格，输入、输出、缓存和服务等级要分别看。

    查看分组与价格说明 →

  2. 创建一把单独测试的 Key

    在API 密钥中选择对应分组，并核对 Key 的可用额度、有效期和模型范围。Key 的额度上限与账号余额需要同时满足调用要求。不要把 Key 发到帖子、群聊或本页。

  3. 按正在使用的客户端配置

    先打开对应教程，填入地址、自己的 Key 和完整模型名。不要把不同客户端的地址格式混用；修改配置后，确认当前客户端会话实际读到了新设置。

    Codex 教程Claude Code 参考Gemini CLI 参考其他接入文档

    Claude Code、Gemini CLI 的链接提供配置参考，不代表完整客户端流程已由本页实测。模型列表可读取，也不代表工具调用、长会话等功能都已验证。

  4. 发送一条短请求，核对日志

    先让模型“只回复：接入成功”。关闭自动循环、批量任务，暂时去掉图片、工具调用和超长历史。收到回复后，打开使用日志，按时间核对模型、状态、Token 和扣费，再用一个小任务检查你真正需要的功能。

    客户端超时后先查日志，避免重复执行。基础调用成功，也不代表后续每种任务都兼容。
