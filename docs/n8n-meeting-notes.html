LinkAGI

把会议笔记整理成待办

用这份 n8n 模板提取谁答应做什么、什么时候交，并保留对应的原话，方便回头核对。

下载 n8n 工作流（JSON） · 备用下载

怎么跑

  1. 在 n8n 工作流菜单选 Import from File，导入下载的 JSON。
  2. 使用 LinkAGI 时，在控制台创建 DeepSeek 分组的 Key。打开 Extract action items 节点，选择或创建 Header Auth 凭据，名称填 Authorization，值填 Bearer 你的Key。
  3. 点 Execute Workflow，在 Action items 查看结果。模板自带虚构笔记。换成自己的内容时，改 Meeting notes 节点即可。

默认模型是 deepseek-v4.1-flash，运行会把笔记发送给所选服务并按量计费。只用你有权发送的笔记。换供应商时一起改接口地址、模型和凭据。
