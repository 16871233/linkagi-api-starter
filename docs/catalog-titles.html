给商品表加一列英文标题

手里有一张 SKU 表，要做英文目录？把它另存为 UTF-8 CSV，脚本会逐行翻译标题，把英文放进新文件的 title_en 列。提示词要求保留型号、容量和件数。

下载脚本和两条示例商品 · 查看 Python 源码

先跑一条

  1. 解压下载包。在 LinkAGI 控制台创建 DeepSeek 分组的 API Key。
  2. 用 Python 3 在解压目录运行下面的命令，按提示输入 Key。脚本只使用 Python 标准库。
python3 translate_titles.py example.csv result.csv

Python 在 Windows 里如果叫 py，把命令开头换成 py。用 Excel 打开 result.csv，检查型号、数量和单位。确认后换自己的文件，例如一次处理前 20 条非空标题：

python3 translate_titles.py products.csv products-en.csv --limit 20

输入表头需要有 sku 和 title。脚本只把标题发给接口，每条调用一次 deepseek-v4.1-flash，会产生 API 费用。输出文件保留 SKU、原标题和译文。出错时脚本会显示停在哪一行，已经写出的翻译仍在文件里。
