02 / 第一次使用

从注册到看见调用记录

  1. 注册并核对余额

    完成邮箱验证后，在钱包查看实际到账余额。注册账号本身不等于已有可调用额度。

  2. 选模型，创建 Key

    先看模型广场的价格和分组，再到API 密钥创建测试 Key。首次使用建议设置额度与有效期。

  3. 填入客户端，发送短请求

    选择上方对应教程，填入地址、Key 和完整模型名。先让模型回复一句简短的话，暂时关闭自动循环与批量任务。

  4. 在日志里看结果

    打开使用日志，按调用时间核对模型、Token、响应状态和实际扣费。再用一个小任务评估是否适合继续使用。

可以先试用吗？

注册不会自动赠送调用额度。需要试用安排，请联系客服确认当前方式、可用模型与额度，余额到账后再调用。

03 / 先估算，再调用

这次任务大概花多少？

从模型广场填入当前人民币单价。输入和输出分别计费；下面只是普通文本 Token 的基础估算。

费用 = 输入 Token × 输入单价 / 100万
+ 输出 Token × 输出单价 / 100万

不含缓存、图片、音频、工具调用或额外费项。请使用已包含分组倍率的实际单价，重试产生的用量也要计入。最终以调用日志为准。
